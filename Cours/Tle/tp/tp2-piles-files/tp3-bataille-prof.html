Rappel : la file (FIFO)

Une file est une structure de données où l'on ajoute à un bout (la queue) et où l'on retire à l'autre (la tête) : premier arrivé, premier sorti (*First In, First Out*). Comme la file d'attente d'une caisse.

OpérationEffet
f = File()crée une file vide
f.est_vide()renvoie True si la file est vide
f.enfiler(x)ajoute x à la queue
f.defiler()retire l'élément de tête et le renvoie (erreur si vide)
f.taille()nombre d'éléments

Les règles de la bataille (version du TP)

  • Un jeu de 52 cartes est mélangé puis distribué une carte sur deux à chaque joueur : chaque joueur a une file de 26 cartes.
  • À chaque tour, les deux joueurs défilent leur carte du dessus. La plus forte gagne (2 < 3 < … < 10 < Valet < Dame < Roi < As).
  • Le gagnant enfile les cartes gagnées à la queue de sa file : pour chaque paire de cartes jouées (une de chaque joueur), il enfile d'abord sa propre carte, puis celle de son adversaire. Les paires sont enfilées dans l'ordre où elles ont été jouées.
  • Égalité (« bataille ») : les deux cartes vont dans un pot ; chaque joueur défile aussitôt une nouvelle carte, et ainsi de suite jusqu'à ce que l'une l'emporte ; le vainqueur enfile tout le pot selon la règle ci-dessus. Si, après une égalité, un joueur n'a plus de carte, il perd le pot (J1 est vérifié en premier).
  • La partie s'arrête quand un joueur n'a plus de carte.

Une carte est un tuple (valeur, couleur) : (14, "♠") est l'As de pique. Les valeurs vont de 2 à 14 (11 = Valet, 12 = Dame, 13 = Roi, 14 = As).

Sont fournis : creer_paquet(), melanger(paquet, graine) (mélange reproductible : la même graine donne toujours le même mélange), nom_carte(carte), fabrique(liste) (crée une file contenant les éléments de la liste) et contenu_file(f) (la liste des éléments d'une file, sans la vider).
