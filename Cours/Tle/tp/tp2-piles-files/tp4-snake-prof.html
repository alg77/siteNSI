Le corps du serpent est une file

Chaque case du corps est représentée par un couple (x, y) : x est la colonne (0 à gauche), y la ligne (0 en haut, elle augmente vers le bas).

À chaque déplacement du serpent :

  • la nouvelle tête est enfilée (elle arrive à la queue de la file) ;
  • la queue du serpent est défilée (elle sort par la tête de la file), sauf si le serpent vient de manger une pomme : il grandit d'une case.

C'est exactement le comportement d'une file (FIFO) : la case la plus ancienne est la première à sortir.

corps = File : [(1,1), (2,1), (3,1)]      ← ordre : queue du serpent → tête du serpent
                 queue          tête
avancer vers la droite : on enfile (4,1) et on défile (1,1)
corps = File : [(2,1), (3,1), (4,1)]

La classe File est fournie (est_vide, enfiler, defiler, taille) ainsi que fabrique(liste) (crée une file à partir d'une liste, le 1ᵉʳ élément en tête) et contenu_file(f) (liste des éléments, sans vider la file : pour afficher ou tester).

Règle du jeu

Le serpent meurt s'il sort de la grille ou s'il rentre dans une case de son propre corps (queue comprise, pour simplifier).
