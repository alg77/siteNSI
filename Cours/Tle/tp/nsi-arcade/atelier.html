💡 Entrées et essais personnels

Pour input(), écris à l’avance une réponse par ligne. S’il manque une réponse, Python affiche une erreur EOFError.

Ajoute tes appels et tes assert en fin de fichier pour essayer une fonction, puis clique sur Exécuter. Les tests fournis n’exécutent pas le bloc if __name__ == "__main__".

Voir les tests et leurs attentes
Les tests unitaires vérifient les fonctions séparément ; les tests complets ajoutent des enchaînements et cas limites. Tu peux les lancer dans l’ordre que tu souhaites. Un TODO produit un échec explicatif.
💡 Comprendre un échec
AssertionError : le résultat ne correspond pas à l’attente. NotImplementedError : une fonction reste à écrire. SyntaxError : vérifie la ligne indiquée. raise déclenche une exception ; return renvoie une valeur.
Le bouton Arrêter interrompt même une boucle infinie. Limite : 10 secondes pour un programme ou pour chaque test. La console est limitée à 20 000 caractères. Un nouveau lancement crée un environnement Python neuf.
