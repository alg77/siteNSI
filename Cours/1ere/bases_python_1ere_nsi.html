Vocabulaire et variables

🐍 Sur cette page
Les blocs de code sont modifiables et exécutables dans le navigateur (Pyodide, un vrai interpréteur Python). Clique sur ▶ Exécuter. Quand un programme utilise input(), une fenêtre s’ouvre pour la saisie. Prédis toujours l’affichage avant d’exécuter !

Programme et instructions

  • Un algorithme est une suite finie d’étapes qui permet d’atteindre un but.
  • Un programme est la traduction d’un algorithme dans un langage compréhensible par l’ordinateur, ici Python.
  • Un programme est une suite d’instructions exécutées de haut en bas, une par une : c’est une séquence.
  • Python est interprété : en cas d’erreur, le programme s’arrête à la ligne fautive et affiche un message.

Variables et affectation

📋 Définition — Variable
Un nom associé à une valeur. On peut l’imaginer comme une étiquette collée sur une valeur.
  • L’affectation nom = valeur : Python calcule d’abord la partie droite, puis colle l’étiquette nom sur le résultat.
  • = affecte une valeur ; == compare deux valeurs (voir partie II).
Clique sur ▶ Exécuter pour lancer ton code.

Affichage attendu : 70

🔑 À retenir
On lit pv = pv - 30 : « pv prend la valeur pv − 30 ». Ce n’est pas une équation !

Nommer une variable

  • Caractères autorisés : lettres non accentuées, chiffres et _ (tiret du 8).
  • Le nom ne commence pas par un chiffre, ne contient ni espace ni tiret.
  • Python distingue majuscules et minuscules : nom et Nom sont deux variables différentes.
  • Un nom ne peut pas être un mot-clé du langage (if, for, def, while…). Il doit être significatif.

Expressions

📋 Définition — Expression
Un calcul qui produit une valeur. Exemple : 3 + 5 a pour valeur 8.
  • resultat = 3 + 5 : on évalue l’expression, puis on affecte sa valeur à resultat.
  • Les priorités sont celles des mathématiques ; les parenthèses sont prioritaires.

Afficher et saisir

Afficher avec print

  • print(...) affiche une ou plusieurs valeurs, séparées par des virgules (affichées avec un espace).
  • print affiche seulement : il ne modifie aucune variable et ne « renvoie » rien.

Saisir avec input

  • input("question") affiche la question, attend que l’utilisateur tape une réponse puis appuie sur Entrée.
  • input renvoie toujours une chaîne (str), même si on tape un nombre.
  • Pour calculer : int(input(...)) (entier) ou float(input(...)) (décimal).

Défi : le nombre mystère

a) Écrire une fonction comparer(proposition, secret) qui renvoie "Trop bas", "Trop haut" ou "Gagné".
b) Écrire le jeu : l’ordinateur tire un nombre entre 1 et 100 avec random.randint ; le joueur propose tant qu’il n’a pas trouvé ; on affiche à chaque fois la réponse de comparer, puis le nombre d’essais à la fin.

À toi de coder :

Clique sur ▶ Exécuter pour lancer ton code.
import random

def comparer(proposition, secret):
    if proposition < secret:
        return "Trop bas"
    elif proposition > secret:
        return "Trop haut"
    else:
        return "Gagné"

secret = random.randint(1, 100)
reponse = ""
essais = 0
while reponse != "Gagné":
    proposition = int(input("Ta proposition ? "))
    essais = essais + 1
    reponse = comparer(proposition, secret)
    print(reponse)
print("Trouvé en", essais, "essais")

Tests de comparer : (3, 7) → Trop bas ; (9, 7) → Trop haut ; (7, 7) → Gagné.
