01 · Comprendre et pratiquer

Variables et affectation

Un programme exécute les instructions dans l’ordre, de haut en bas.

Une variable est un nom associé à une valeur. Choisis un nom explicite, sans espace, qui ne commence pas par un chiffre.

Le signe = affecte la valeur calculée à droite au nom écrit à gauche. Il ne signifie pas « est égal à » dans une comparaison.

Une nouvelle affectation remplace la valeur précédente. # introduit un commentaire ignoré à l’exécution.

Python 3
places = 24
places = places - 3
print(places)
# Trois places ont été réservées.
À l’écran
21
Attention

Python distingue places et Places. Lire un nom avant son affectation provoque une erreur.

02 · Comprendre et pratiquer

Types et calculs

int représente les entiers ; float représente les nombres à virgule flottante, écrits avec un point.

str représente une chaîne de caractères entre guillemets. bool représente True ou False.

type(valeur) permet d’observer le type d’une valeur.

+, -, * et ** calculent une somme, une différence, un produit et une puissance.

/ effectue une division ; // donne le quotient entier arrondi vers moins l’infini ; % donne le reste. Pour les entiers positifs, on retrouve la division euclidienne.

Les parenthèses imposent l’ordre des calculs. Sinon, les puissances précèdent les produits et divisions, qui précèdent les sommes.

Python 3
print(17 // 5, 17 % 5)
print(17 / 5)
print(2 + 3 * 4)
print((2 + 3) * 4)
À l’écran
3 2
3.4
14
20
Attention

"12" est du texte et 12 est un entier. "12" + "3" donne "123". Les float peuvent représenter certaines valeurs de façon approchée.

04 · Comprendre et pratiquer

Comparer et combiner des conditions

== teste l’égalité ; != teste la différence. <, <=, > et >= comparent deux valeurs.

Une comparaison produit un booléen : True ou False.

and est vrai si les deux conditions sont vraies. or est vrai si au moins une condition est vraie.

not inverse une condition. Les parenthèses rendent les combinaisons plus lisibles.

0 <= note <= 20 vérifie les deux bornes incluses. On peut aussi écrire note >= 0 and note <= 20.

Python 3
age = 17
autorisation = True
print(age >= 18)
print(age >= 16 and autorisation)
print(not autorisation)
À l’écran
False
True
False
Attention

Pour accepter "oui" ou "o", écris reponse == "oui" or reponse == "o". Chaque comparaison doit être complète.

05 · Comprendre et pratiquer

Choisir avec if, elif et else

if condition: exécute le bloc indenté seulement si la condition est vraie.

elif condition: teste une autre possibilité si les tests précédents ont échoué.

else: traite tous les cas restants. Il ne porte pas de condition.

Dans une chaîne if / elif / else, au plus un bloc est exécuté. Deux if indépendants peuvent tous deux s’exécuter.

Le deux-points ouvre le bloc. Indente de quatre espaces et aligne les instructions du même bloc.

Python 3
age = 14
if age < 12:
    prix = 5
elif age < 18:
    prix = 8
else:
    prix = 12
print(prix)
À l’écran
8
Attention

L’ordre des tests compte : tester note >= 10 avant note >= 16 dans une chaîne peut masquer le cas « très bien ».

06 · Comprendre et pratiquer

Répéter avec for et range

for parcourt les éléments d’une séquence, par exemple les entiers produits par range ou les caractères d’un texte.

range(n) produit les entiers de 0 à n - 1. range(4) produit donc quatre valeurs.

range(debut, fin) inclut debut et exclut fin.

range(debut, fin, pas) fixe l’écart entre deux valeurs. Le pas ne peut pas être nul.

Le bloc indenté est exécuté une fois par valeur. Après le bloc, une instruction désindentée s’exécute une seule fois.

Python 3
for numero in range(1, 4):
    print("Tour", numero)
print("Terminé")
for lettre in "NSI":
    print(lettre)
À l’écran
Tour 1
Tour 2
Tour 3
Terminé
N
S
I
Attention

range(1, 5) ne contient pas 5. range(5, 1) est vide : utilise un pas négatif pour descendre.

07 · Comprendre et pratiquer

Compteurs, accumulateurs et traces

Un compteur mesure un nombre d’événements. Initialise-le à zéro avant la boucle et augmente-le quand la condition est satisfaite.

Un accumulateur construit une somme ou un produit. Une somme commence à 0 ; un produit commence à 1.

total += valeur est une écriture abrégée de total = total + valeur.

Pour comprendre une boucle, note la valeur des variables après chaque tour dans un tableau de trace.

Le placement de print à l’intérieur ou à l’extérieur de la boucle distingue les résultats intermédiaires du résultat final.

Python 3
somme = 0
for n in range(1, 5):
    somme = somme + n
    print(n, somme)
À l’écran
1 1
2 3
3 6
4 10
Attention

Initialiser somme = 0 dans la boucle efface le résultat des tours précédents.

08 · Comprendre et pratiquer

Répéter tant que : while

while condition: répète son bloc tant que la condition est vraie.

La condition est testée avant chaque tour : si elle est fausse au départ, aucun tour n’est exécuté.

Initialise les variables avant la boucle, fais évoluer l’état dans le bloc et identifie ce qui rendra la condition fausse.

Utilise souvent for lorsque le parcours est connu, et while lorsque l’arrêt dépend d’un seuil ou d’une saisie.

Une boucle qui ne peut pas atteindre sa condition d’arrêt peut tourner indéfiniment.

Python 3
energie = 3
while energie > 0:
    print(energie)
    energie -= 1
print("Repos")
À l’écran
3
2
1
Repos
Attention

Oublier energie -= 1 maintient la condition vraie. Dans un éditeur Python, interromps alors le programme avec le bouton Stop.

09 · Comprendre et pratiquer

Saisies répétées et choix de boucle

Pour redemander une saisie, lis une première valeur avant while, puis renouvelle-la dans le bloc.

Une sentinelle est une valeur spéciale qui termine la saisie. Elle ne doit pas être ajoutée au résultat.

break interrompt immédiatement la boucle la plus proche. C’est un outil complémentaire ; commence par savoir écrire une condition d’arrêt explicite.

Teste aussi les cas où la première saisie est déjà valide ou déjà la sentinelle.

Python 3
nombre = 1
total = 0
while nombre <= 3:
    total += nombre
    nombre += 1
print(total)
À l’écran
6
Attention

Une saisie répétée doit pouvoir changer la condition. Ne suppose pas que l’utilisateur fera toujours un choix valide.

10 · Comprendre et pratiquer

Fonctions : paramètre, appel et return

def nom(parametre): définit une fonction. Son corps ne s’exécute que lorsqu’on l’appelle.

Un paramètre est un nom utilisé dans la définition. Un argument est la valeur fournie lors d’un appel.

return renvoie une valeur à l’appelant et termine la fonction. Sans return exécuté, la fonction renvoie None.

print affiche une valeur mais ne la renvoie pas à l’appelant. Une fonction de calcul renvoie généralement son résultat.

Les variables créées dans une fonction sont normalement locales à cet appel. Utilise des paramètres et return pour échanger des valeurs.

Python 3
def carre(x):
    return x * x

resultat = carre(5)
print(resultat)
print(carre(3) + 1)
À l’écran
25
10
Attention

Ne remplace pas return par print si tu veux réutiliser le résultat dans un calcul.

11 · Devenir autonome

Tester, expliquer, transférer

Une méthode en quatre étapes
  1. Prédire le résultat sur papier.
  2. Écrire et exécuter dans ton éditeur Python.
  3. Comparer au résultat attendu et tester les bornes.
  4. Modifier une contrainte sans regarder la correction.

Reconnaître les erreurs

SyntaxError / IndentationError : vérifie les deux-points, les parenthèses et l’indentation.

NameError : vérifie le nom et son affectation avant utilisation.

TypeError / ValueError : vérifie le type des valeurs et la conversion des saisies.

Erreur logique : le programme s’exécute mais donne un mauvais résultat ; construis une trace des variables.

Parcourir un texte ou un intervalle connufor

  • Je sais prédire une sortie et tracer une boucle.
