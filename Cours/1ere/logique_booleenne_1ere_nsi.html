01 — Des booléens partout

Des booléens partout

Depuis le début de l’année, tu écris des booléens sans le savoir.
Chaque condition d’un if ou d’un while en est un, comme chaque colonne « x < 20 ? » d’un tableau de suivi.

Définition

Un booléen est une valeur qui ne peut prendre que deux états : vrai ou faux.

En Python, ce sont True et False, de type bool. En logique et en électronique, on les note souvent 1 et 0.

Le mot vient de George Boole (1815–1864), mathématicien anglais qui a inventé un calcul sur le vrai et le faux, comme on calcule sur les nombres.
Un siècle plus tard, Claude Shannon a montré que ce calcul décrit exactement les circuits électroniques : c’est la base de tous les processeurs.

Les comparaisons produisent des booléens

<=inférieur ou égal7 <= 7True

Une comparaison est une expression booléenne : on peut ranger sa valeur dans une variable.

À retenir

if age >= 18: teste si l’expression age >= 18 vaut True.
Une condition n’est rien d’autre qu’une expression booléenne.

Attention

True et False s’écrivent avec une majuscule et sans guillemets.
"True" est une chaîne de caractères, pas un booléen.

02 — Les opérateurs not, and, or

Les opérateurs not, and, or

On combine des booléens avec trois opérateurs. Leur comportement se résume dans une table de vérité : une ligne par combinaison possible des entrées.

not a la négation
vrai si a est faux : elle inverse la valeur.
not True → False
a and b le ET
vrai si a et b sont vrais tous les deux.
True and False → False
a or b le OU
vrai si au moins un des deux est vrai.
True or False → True
abnot aa and ba or b
00100
01101
10001
11011

On écrit souvent les tables avec 0 pour faux et 1 pour vrai. On range les lignes dans l’ordre de l’écriture binaire : 00, 01, 10, 11.

Le OU logique est inclusif

Dans la langue courante, « fromage ou dessert » veut souvent dire « l’un ou l’autre, pas les deux ».
En logique, a or b est vrai aussi quand les deux sont vrais.

Les différentes notations

FrançaisPythonLogiqueÉlectronique
NON anot a¬aa̅
a ET ba and ba ∧ ba · b
a OU ba or ba ∨ ba + b

Priorités

Comme × passe avant + en calcul, not passe avant and, qui passe avant or.

python
print(True or False and False)    # and d’abord : True or False → True
print((True or False) and False)  # parenthèses : True and False → False
Conseil

Dès qu’une expression mélange and et or, mets des parenthèses.
Ton programme sera plus lisible, même si elles ne sont pas obligatoires.

03 — Le ou exclusif (xor)

Le ou exclusif (xor)

Définition

Le ou exclusif, noté xor ou ⊕, est vrai si exactement un des deux est vrai.
C’est le « fromage ou dessert » du restaurant : l’un ou l’autre, mais pas les deux.

aba xor b
000
011
101
110

Python n’a pas de mot-clé xor. Avec deux booléens, on écrit a != b : c’est vrai exactement quand a et b sont différents.
On peut aussi le construire avec les trois opérateurs : (a or b) and not (a and b).

Une application : additionner deux bits

En binaire : 0 + 0 = 0, 0 + 1 = 1, 1 + 0 = 1 et 1 + 1 = 10 (on écrit 0 et on retient 1).

abretenuesomme
0000
0101
1001
1110
À retenir

La colonne somme est exactement la table de a xor b.
La colonne retenue est exactement la table de a and b.
Ce petit circuit s’appelle un demi-additionneur : en l’enchaînant, un processeur additionne des nombres de 64 bits.

int(True) vaut 1 et int(False) vaut 0 : on retrouve l’écriture avec des bits.

Ou inclusif ou exclusif ?

04 — Table de vérité d’une expression

Table de vérité d’une expression

Pour connaître une expression booléenne dans tous les cas, on dresse sa table de vérité.

La méthode
  1. Avec n variables, il y a 2n lignes : 4 lignes pour 2 variables, 8 pour 3, 16 pour 4.
  2. On écrit les combinaisons dans l’ordre du binaire : 000, 001, 010, … , 111.
  3. On ajoute une colonne par sous-expression, en respectant les priorités.
  4. La dernière colonne donne la valeur de l’expression.

Exemple : E = (a and not b) or c

abcnot ba and not bE
000100
001101
010000
011001
100111
101111
110000
111001

Python peut dresser cette table pour nous, avec trois boucles imbriquées.

Expressions équivalentes

Deux expressions sont équivalentes si elles ont la même table de vérité.
On peut alors remplacer l’une par l’autre dans un programme, par exemple pour le rendre plus lisible.

05 — Les lois de De Morgan

Les lois de De Morgan

Les lois de De Morgan

not (a and b) est équivalent à (not a) or (not b).
not (a or b) est équivalent à (not a) and (not b).

En français : la négation d’un ET est le OU des négations, et la négation d’un OU est le ET des négations.

Augustus De Morgan (1806–1871) était un contemporain et ami de George Boole.
On démontre ces lois en comparant les tables de vérité des deux côtés.

abnot (a and b)not a or not bnot (a or b)not a and not b
001111
011100
101100
110000
Clique sur ▶ Exécuter pour lancer ton code.

On obtient True sur toutes les lignes : les deux lois sont vraies dans tous les cas.

À quoi ça sert ? Écrire le contraire d’une condition

ConditionSon contraire (avec not)Son contraire (sans not)
n >= 10 and n <= 20not (n >= 10 and n <= 20)n < 10 or n > 20
vitesse < 100 and altitude < 1000not (vitesse < 100 and altitude < 1000)vitesse >= 100 or altitude >= 1000
eau < 2 or jours > 5not (eau < 2 or jours > 5)eau >= 2 and jours <= 5
Attention

Le contraire de < est >=, et non >.
Le contraire de == est !=.

Le piège du « ni… ni… »

python
jour = "lundi"
if jour != "samedi" or jour != "dimanche":   # ✗ toujours vrai !
    print("Jour de cours")
if jour != "samedi" and jour != "dimanche":  # ✓
    print("Jour de cours")

« C’est le week-end » s’écrit jour == "samedi" or jour == "dimanche".
D’après De Morgan, son contraire est jour != "samedi" and jour != "dimanche".
Avec un or, la condition est toujours vraie : un samedi, le jour est bien différent de dimanche !

Et dans une boucle while

On répète tant que la condition est vraie, donc on sort quand elle devient fausse.
Pour écrire la condition du while, on prend le contraire de la condition d’arrêt.

python
# On s’arrête quand le code est bon OU quand il ne reste plus d’essai.
# On continue donc tant que le code est faux ET qu’il reste des essais.
essais = 3
code = ""
while code != "1234" and essais > 0:
    code = input("Code ? ")
    essais = essais - 1

La condition du while

Dans un jeu, le combat continue tant que le héros a encore des PV et que le monstre aussi.

  1. Écris la condition du while.
  2. Quand on sort de la boucle, quelle condition est vraie ? Écris-la sans not.

python

pv_monstre = 25
while pv_heros > 0 and pv_monstre > 0:
    pv_monstre = pv_monstre - 8

06 — L’évaluation paresseuse

L’évaluation paresseuse

Python évalue and et or de gauche à droite et s’arrête dès que le résultat est connu.

ExpressionSi la partie gauche vaut…RésultatLa partie droite est-elle évaluée ?
gauche and droiteFalseFalsenon : faux ET n’importe quoi donne faux
gauche and droiteTruela valeur de droiteoui
gauche or droiteTrueTruenon : vrai OU n’importe quoi donne vrai
gauche or droiteFalsela valeur de droiteoui
Clique sur ▶ Exécuter pour lancer ton code.

B n’est jamais évalué : le résultat est connu dès A.

À quoi ça sert ? Éviter des erreurs

Clique sur ▶ Exécuter pour lancer ton code.

Dans la première ligne, la division n’est jamais faite. Dans la seconde, elle est faite en premier.

À retenir

L’ordre des conditions compte.
On place d’abord la condition « de sécurité », celle qui garantit que la suite peut être calculée sans erreur.

Pour aller plus loin

Cette évaluation est dite paresseuse ou séquentielle.
Elle est très utile avec les listes : dans i < len(t) and t[i] == 0, on vérifie que l’indice existe avant de lire la case.

On a x = 0. Pour chaque expression, donne sa valeur ou indique qu’elle provoque une erreur.

  1. x == 0 or 10 / x > 2
  2. 10 / x > 2 or x == 0

07 — Les fonctions booléennes

Les fonctions booléennes

Une fonction qui renvoie True ou False répond à une question par oui ou par non.
Par convention, son nom commence par est : est_pair(n), est_majeur(age), est_bissextile(annee).

Renvoyer directement la condition

correct, mais long
def est_pair(n):
    if n % 2 == 0:
        return True
    else:
        return False
mieux
def est_pair(n):
    return n % 2 == 0
À retenir

n % 2 == 0 est déjà un booléen : il suffit de le renvoyer.
De même, on écrit if est_pair(n): et non if est_pair(n) == True:.

Exemple : les années bissextiles

Une année est bissextile si elle est divisible par 4 mais pas par 100, ou si elle est divisible par 400.
Ainsi 2024 et 2000 sont bissextiles, mais pas 2026 ni 1900.

Clique sur ▶ Exécuter pour lancer ton code.
Tester une fonction booléenne

Choisis au moins un cas où elle doit renvoyer True, un cas où elle doit renvoyer False, et les cas limites.
Pour est_bissextile, 1900 et 2000 sont les cas qui piègent.
